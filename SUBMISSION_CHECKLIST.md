# Submission checklist

Do not submit until every box is true.

- [ ] Public GitHub repository opens while signed out.
- [ ] Repository contains frontend **and** backend source.
- [ ] Repository has at least **3 chronological commits**.
- [ ] `README.md` has setup/deployment instructions.
- [ ] `.env.example` is committed; real secrets/data files are not.
- [ ] Live HTTPS URL opens in a private/incognito window.
- [ ] Persistent disk/database survives a redeploy/restart.
- [ ] Signup and login work.
- [ ] A user only sees their own quests/data.
- [ ] Create/read/update/delete quest flow works.
- [ ] Completing a quest updates XP, level progress, attribute, streak, and gold.
- [ ] Page refresh keeps persisted progress.
- [ ] Loot purchase/inventory works.
- [ ] Empty quest produces a clear error instead of a crash.
- [ ] Offline/network failure produces feedback and no fake completion.
- [ ] No console/runtime errors during the main demo path.
- [ ] Mobile layout tested around 360–390px width.
- [ ] Keyboard: Tab/Shift+Tab/Enter/Space can operate core UI.
- [ ] `/robots.txt`, `/sitemap.xml`, `/api/health` all work.
- [ ] Final `PUBLIC_URL` is set correctly for canonical/OG/sitemap output.
- [ ] Walkthrough video is 90–180 seconds and under 100 MB.
- [ ] Video link works while signed out / without special permission.
- [ ] `npm test` passes.
- [ ] `npm run smoke` passes.
