FAQ

Before you enter the realm.

Is my progress actually saved?

Yes. Accounts, quests, XP, streaks, attributes, inventory and activity history are stored in the server database.

Can I use it on mobile?

Yes. The layout adapts from phones to desktop and core actions use standard keyboard controls.

Can I fake XP from the browser?

No payout is trusted from the browser. XP, gold, level progression and attribute gains are calculated by the backend.

What happens when the network drops?

The UI reports offline state and optimistic changes roll back if the server request fails.
