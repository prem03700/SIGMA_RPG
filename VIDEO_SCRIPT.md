# 90–180 second illustration video script

Target: **about 2 minutes**. Keep the browser console closed unless you intentionally show the persistence proof.

**0:00–0:15 — Landing page**
Show the hero, scroll through the system/game-loop sections, and mention that the app converts real actions into quests, XP, attributes, streaks, gold, and rewards.

**0:15–0:35 — Signup/login**
Create a fresh account. Point out that progress is account-backed and persisted by the server database.

**0:35–0:55 — Create a quest**
Click **Forge quest**. Create a hard quest such as “Finish hackathon landing page”, choose an attribute, and save it. Briefly show edit/delete controls.

**0:55–1:25 — Complete + progression**
Complete the quest. Keep the XP/gold reward toast on screen. Show the updated XP bar, attribute value, streak, and activity log. If practical, create enough quests beforehand so this completion triggers the level-up overlay.

**1:25–1:42 — Economy**
Open **Loot vault**, purchase a low-cost reward with earned gold, and show it in inventory. Equip a badge/theme if available.

**1:42–2:00 — Persistence proof**
Refresh the page. Show that the completed quest, XP, streak, inventory, and activity are still present. Sign out and sign back in if time allows.

**2:00–2:10 — Finish**
Show the live URL and GitHub repository. End on the command center rather than a blank tab.

## Recording constraints

- Keep the file **under 100 MB**.
- Keep the duration **between 90 and 180 seconds**.
- Host it in the repository or at a public link that does not require viewer login.
